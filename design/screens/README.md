# Visual review

App screenshots are generated by the Playwright flows and visual.spec.ts in portrait (390×844) and landscape (844×390), with both light and dark surfaces. Round screenshots use landscape gameplay; portrait records the paused overlay. Recording uses the browser's fake camera, so its green test image is expected.

fonts/ holds 20 full-size longest-card renders for each of three finalists in both orientations, plus measured file sizes and fitting minima. Archivo Black was chosen; see DECISIONS.md. The fake home-screen icon review shows the mark at 60×60 and 180×180 CSS pixels.

These are browser screenshots, not proof of physical iPhone behaviour. Owner-code success screens are absent because no passcode was supplied. Real-device acceptance is listed in README.md.

Review completed for the screen contact sheets, full-size representative sheets/rounds/results, both font comparison matrices and icon sizes. Long-title sizing and the dark wordmark were adjusted after inspection. Browser installability scored 100/100; see lighthouse-summary.json. Passcode success requires the owner-supplied code and is not represented as verified.
