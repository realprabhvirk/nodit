# Optional brand artwork prompts

The bundled hand-built SVG is the shipping default. Owner-provided brand art may replace it after visual review.

## App icon — app-icon-1024.png
Create a 1024×1024 app icon on solid cobalt #2748E8. Centre a geometric sky #7FB2F0 forehead beneath a cloud #F4F5F7 landscape card containing a cobalt downward check. Keep 10% safe margins. Flat vector style, solid fills, no gradients, no shadows, no texture, no text. Output app-icon-1024.png.

## Maskable — maskable-1024.png
Create a 1024×1024 maskable app icon on solid cobalt #2748E8. A geometric sky #7FB2F0 forehead beneath a cloud #F4F5F7 landscape card and a cobalt downward check; all meaningful artwork inside the central 80% diameter circle. Flat vector style, solid fills, no gradients, no shadows, no texture, no text. Output maskable-1024.png.

## Monochrome mark — mark-1024.png
Create a 1024×1024 monochrome mark in ink #0F1B2D on cloud #F4F5F7: a broad geometric forehead beneath a landscape card with a cut-out downward check. Centre it with 10% margin. Flat vector style, solid fills, no gradients, no shadows, no texture, no text. Output mark-1024.png.

## Launch colour — no image
Use cloud #F4F5F7 in light mode and deep navy #0A1220 in dark mode. No image or text; configure native launch backgrounds through app metadata.

Keep 64 px clear margins. Flat vector style, solid fills, no gradients, no shadows, no texture. Output social-1200x630.png.
